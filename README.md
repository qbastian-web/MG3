# MG3
## Devlog
1. The default values for ints and bools seems to be 0, representing 0 and false respectively. The default value for a float is 0.0, and the default value for a string is "", an empty string.
2. The Update method is automatically called by the Unity engine every frame.
3. The KickWeapon class uses the timer to deactivate itself once the game is over; it accomplishes this by checking the state of the timer every frame in the Update method and acting accordingly.
